### Cyberpunk Survivor - Steam: [https://store.steampowered.com/app/4866450/Cyberpunk_Survivor/](https://store.steampowered.com/app/4866450/Cyberpunk_Survivor/)
***Cyberpunk Survivor**, a game I have developed using the independent developer identity **mrtcnbykl**, has been released on Steam on September 21, 2026.*

<br>

*Cyberpunk Survivor*, with its art design and gameplay inspired by retro arcade games, was developed using the C# programming language via the Unity Game Engine.

- The game's art designs were created by combining works that artists have shared publicly with my own designs.
- The game was developed through a cycle of thinking, designing, researching, and implementing.
- The use of generative artificial intelligence was avoided in the design and programming processes.
